

Create a modern, production-ready web application for managing a Tamil Nadu Panchayat-level political organization and its daily operations.

### Project Goal

Build a responsive web application that helps local party administrators manage:

* Party cadres and members
* Panchayat activities
* Events and meetings
* Complaints and public grievances
* Monthly subscription (Santhaa) collections
* Role hierarchy and responsibilities
* Calendar and task tracking
* Ward/Kilai-level administration

The application should be suitable for real-world usage by a local political unit in Tamil Nadu.

---

## Technical Requirements

### Stack

* Frontend: React + Next.js (App Router)
* Backend: Supabase
* Database: PostgreSQL (Supabase)
* Authentication: Supabase Auth
* Hosting: Vercel
* UI: Tailwind CSS + ShadCN UI
* State Management: React Query / TanStack Query
* Forms: React Hook Form + Zod
* Calendar: FullCalendar
* Charts: Recharts
* RBAC implemented both in frontend and database policies

# Database Design

Design normalized PostgreSQL schema with:

* users
* roles
* permissions
* role_permissions
* role_hierarchy
* members
* villages
* panchayats
* kilais
* wards
* events
* event_attendance
* complaints
* complaint_history
* subscriptions
* subscription_payments
* accounts
* transactions
* tasks
* notifications
* audit_logs

Use UUID primary keys.

Include:

* Foreign key constraints
* Indexes
* Soft deletes
* Created/Updated timestamps
